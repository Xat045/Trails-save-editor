SE-Crossbell (Crossbell-SaveEditor) — save editor
Trails from Zero · Trails to Azure (PC, Steam)

──────────────────────────────── WHAT IT DOES

  Edits your game save: mira, detective DP, sepith, the combat notebook, play time, difficulty,
  the party, the amount of any item. The save checksums are recalculated automatically, so the game
  accepts the edited save.

──────────────────────────────── REQUIREMENTS

  data.dat must be next to Crossbell-SaveEditor.exe: it holds the item icons, portraits and the game
  tables (item and character names). Without it the editor can't show items or characters.

──────────────────────────────── HOW TO USE

  1. On start, pick the game by its cover and click «Continue».
     To go back, use the «Select game» button at the top.
  2. The «Save folder» is filled in automatically:
       Zero   — C:\Users\<name>\Saved Games\Falcom\Zero
       Azure  — C:\Users\<name>\Saved Games\Falcom\Ao
     «Open save…» — pick savedata.dat from any dataNNNN folder (a slot, a backup, a copy from another
     PC). You can also drop a savedata.dat file onto the window.
  3. Select a slot on the left: dataNNNN, chapter, location and play time.
  4. Tabs:
     • «General» — mira; Detective Notebook: DP and the detective rank (calculated from DP);
       sepith (Earth, Water, Fire, Wind, Time, Space, Mirage); Combat Notebook (battles fought,
       victories and more); play time; difficulty;
     • «Party» — cards in three zones: «In battle» (4 slots), «Reserve» (up to 4), «Can be added»
       (characters who have joined). Drag a card onto another one, or click two cards, to swap them;
       drag a card into «Can be added» to remove it from the party. Guests (KeA, Renne…) are added
       and removed by the story;
     • «Items» — the same categories as in the game, with icons and search by name. Untick «Owned only»
       to add an item you don't have. «All "0" / "1" / "99"» — applies to every visible item at once.
  5. «Save to this slot» — writes the changes to the selected slot. Before that, the slot is copied to the
     «Backups» folder next to the program — you can restore it from there.
     «Save to new slot» — writes the edited save to the first free slot; the selected one stays as it was.
     «Discard changes» — reverts everything to how it was when the slot was opened.

  Close the game or return to the title screen before writing: the game keeps its slots open.

──────────────────────────────── KEYBOARD SHORTCUTS

  Ctrl+S — save to this slot          Ctrl+F — search across all tabs
  Up / Down arrows — next slot        Ctrl + mouse wheel — zoom

──────────────────────────────── NOTES

  • The game loads models and animations per story chapter: a character who isn't in the party at this
    point of the story may show up with someone else's model or none. Test on a new slot.
  • Theme — the «Light / Dark theme» button.
  • Unofficial fan tool. Keep your own backups of your saves.
