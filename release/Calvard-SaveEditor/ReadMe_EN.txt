SE-Calvard (Calvard-SaveEditor) — save editor
Trails through Daybreak · Trails through Daybreak II · Trails beyond the Horizon (PC, Steam)

──────────────────────────────── WHAT IT DOES

  Edits your game save: mira, sepith, difficulty, play time, Total SP and the L.G.C. gauges, the party,
  the amount of any item. The save checksum is recalculated automatically, so the game accepts the
  edited save.

──────────────────────────────── REQUIREMENTS

  data.dat must be next to Calvard-SaveEditor.exe: it holds the item icons, portraits and the game
  tables (item, character and skill names). Without it the editor can't show items or characters.

──────────────────────────────── HOW TO USE

  1. On start, pick the game by its cover and click «Continue».
     To go back, use the «Select game» button at the top.
  2. The «Save folder» is filled in automatically:
       Daybreak     — C:\Users\<name>\Saved Games\Falcom\Kuro
       Daybreak II  — C:\Users\<name>\Saved Games\Falcom\Kuro2
       Horizon      — C:\Users\<name>\Saved Games\Falcom\Kai
     «Open save…» — pick user.dat from any folder (a slot, a backup, a copy from another PC).
     You can also drop a user.dat file onto the window.
  3. Select a slot on the left: saveNNN, chapter, location and play time.
  4. Tabs:
     • «General» — mira, sepith (Earth, Water, Fire, Wind, Time, Space, Mirage, Sepith Mass),
       difficulty (Command Battle and Field Battle), tokens, Arkride Solutions: Total SP and Office Rank
       (calculated automatically), the L.G.C. gauges (Law, Gray, Chaos) with levels, play time;
     • «Party» — cards in three zones: «In battle» (4 slots), «Reserve», «Can be added».
       Drag a card onto another one, or click two cards, to swap them; drag a card into «Can be added»
       to remove it from the party. Van can't be removed. Characters who haven't joined yet in the story
       get level 1 (no weapon or crafts) — test on a new slot;
     • «Items» — the same categories as in the game (Items, Cooking, Weapons, Armor, Acc., Quartz, Mats.,
       Key, Holo Cores, DLC), with icons and search by name. Untick «Owned only» to add an item you
       don't have. «All "0" / "1" / "99"» — applies to every visible item at once.
  5. «Save to this slot» — writes the changes to the selected slot. Before that, the slot is copied to the
     «Backups» folder next to the program — you can restore it from there.
     «Save to new slot» — writes the edited save to the first free slot; the selected one stays as it was.
     «Discard changes» — reverts everything to how it was when the slot was opened.

  Close the game or return to the title screen before writing: the game keeps its slots open.

──────────────────────────────── KEYBOARD SHORTCUTS

  Ctrl+S — save to this slot          Ctrl+F — search across all tabs
  Up / Down arrows — next slot        Ctrl + mouse wheel — zoom

──────────────────────────────── NOTES

  • The game doesn't store Total SP — it adds it up from completed quests; the editor writes the
    difference into the quests' bonuses, so SP can't change before the first quest is completed.
  • Internal game entries (marked ◆: spare book slots, debug weapons, guest gear) are hidden.
    To show them: «About» → «Show internal items (◆)».
  • Theme — the «Light / Dark theme» button.
  • Unofficial fan tool. Keep your own backups of your saves.
